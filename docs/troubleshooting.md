# Troubleshooting Guide

## Before changing anything

If the app still opens, first download a fresh local backup from **Backup**. Do not clear browser data, uninstall the app, or edit a backup file by hand before making that copy.

| What you see | Safe first action | Do not do this |
| --- | --- | --- |
| Working offline | Continue using local records; reconnect later if needed. | Do not expect a connection-restored message to upload records. |
| Sale cannot complete | Check that a product is in the cart, stock is sufficient, and payment amount is valid. | Do not repeatedly submit if the button says it is completing. |
| Customer debt looks wrong | Open the customer history and check recorded repayments. | Do not edit a backup file to change a balance. |
| Backup file is rejected | Choose the original JSON file downloaded by Tallybook. | Do not restore an unknown, edited, or unsupported file. |
| Local record check reports attention | Download a fresh backup, keep the message, and seek help. | Do not delete browser data or use developer tools to remove records. |
| App does not open offline | Connect once to load the latest app shell, then retry. | Do not clear site data before making a backup. |

## Privacy reminder

Backups are readable JSON files and can contain customer and business information. Keep them private, avoid sharing them in public chats, and store copies only in locations you trust.
