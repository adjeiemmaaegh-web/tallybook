## Implemented changes

**Environment.** Installed dependencies, removed hard-coded global TypeScript imports, fixed semantic type errors, repaired stale test fixtures and asynchronous setup tests, pinned Node/pnpm, updated vulnerable dependencies and added reproducible local/browser/Ubuntu CI checks. Fixtures now establish valid company/customer/staff state instead of hiding genuine production errors. Slow real PIN hashing has an explicit test timeout. No failing security check was disabled to obtain a pass.

**Inventory and finance.** Added schema 26's immutable inventory cost events with unique scoped sequence/source identities, safe integer arithmetic, reconstructible FIFO receipt allocation and independent replay validation. Creation/import, purchases, adjustments, stock counts, sales and full sale reversals use the ledger in the same transaction as stock. Sales save line and aggregate COGS; reversals restore original allocations and exact batch quantities. Duplicate/tampered links, insufficient quantities, ledger drift and arithmetic overflow reject the transaction. Legacy quantities and positive adjustments without actual receipt evidence have unknown cost; historical cost is never guessed from today's product price. Reports display unavailable COGS when needed and derive verified costs independently from events and stock movements.

**Tax and business setup.** New businesses default to Ghana, GHS and Mobile Money; registration accepts country and provider labels. Provider names do not approve gateways. Tax remains off until owner configuration, using one explicit rate, registered status and inclusive/exclusive mode. BigInt intermediates calculate invoice tax after discounts, rounded half up. Checkout and quotation totals show tax, stale tax review fails, saved sales/receipts retain the policy and amounts, retries retain the original sale, reversals offset its original tax and backup import rejects altered amounts. Management reports separate recorded tax and sales excluding that tax. Exemptions, compound levies, input tax, jurisdiction-specific invoice compliance and filing are not implemented; no national rate or legal compliance is asserted.

**Write safety and recovery.** Core inventory, sale, purchase, provider, local-commerce and sync configuration writes recheck expected company and permissions inside transactions. Added actor audit entries to several previously uncovered mutations. Company clearing now scopes all main-database tables in one transaction. Restored sync consent is disabled until explicit opt-in. The separate assistant database still prevents a claim of crash-atomic whole-application restore/clear.

**Assistant and intelligence.** A short-lived company-scoped quotation handoff opens an editable review and requires a Save action. Quote-to-sale conversion and its quotation link are atomic; failure rolls back stock, cost and money together. Insights use actual remaining batches for expiry and observed sale-line quantities for SKU volume, exclude reversed sales and state limitations rather than invent forecasts. Dated receivable ageing and persisted approved automation remain missing.

**Mock payments.** Added an explicitly local, in-memory gateway contract supporting both card and MoMo test intents. Disabled is the default. It verifies company isolation, immutable retry intent, success/failure/timeout, duplicate/conflicting events, partial/full refunds, excess-refund rejection and chargebacks.
